# 骨骼锚定图生成系统 · Anchor Sketch

> **当前版本：v0.0.1（静态交互原型）**

## 这东西是干嘛的

一句话：**AI 剧生成之前，先用一张骨架示意图把「这场戏有几个人、站在哪、什么姿势、朝哪个方向」钉死，让人先确认、也让 AI 别瞎脑补。**

剧本里写「三个人在客厅争执」，AI 直接生成经常翻车：人数不对、站位乱来、谁在谁前面全错。这套系统插在**剧本**和**AI 剧生成**中间，先把空间关系锚定成一张图。这张图只讲**关系**，不讲画面——运镜、切换、剪辑、光影全交给下游 AI 发挥。

## v0.0.1 能做什么

这一版是**静态展示层**，用来调交互手感和展示效果。纯前端单文件，双击就能用。

| 功能 | 说明 |
|---|---|
| 人物 / 道具 | 工具条两个按钮添加，画布上拖动改变位置 |
| 姿势 | 选中后一键切换：站 / 坐 / 走 / 挥手（预设模板库） |
| 朝向 | 正 / 右 / 背 / 左，靠火柴人画法本身体现（正面画眼、背面实心、侧面画鼻） |
| 2.5D 画布 | 斜俯视透视地面网格，前大后小体现纵深 |
| 交付 | 一键导出 PNG |
| 其他 | 重置示例、Delete 删除、Esc 取消选中 |

左侧剧本区这版只做静态展示，AI 解析后续接入。

## 快速开始

直接用浏览器打开 `prototype/index.html`（单文件，零依赖，无需构建）。

## 设计目标（已锁定）

1. **产物**：一场景一张静态骨架示意图，2.5D 斜俯视 + 地面网格。
2. **输入**：该场景剧本文本 → AI 解析出初稿 → 人工拖拽微调 → 导出图。
3. **关系语义**：只表达前后 / 左右 / 朝向的相对关系，**不锁机位**。
4. **交付**：图 + 剧本一起喂通用文生视频大模型（可灵 / 即梦 / Sora 类）。
5. **边界**：不做动画、不出 JSON、不调文生视频、不管人物属性（属性归独立的人物建模系统，靠角色名对接）。

完整讨论结论见 [`docs/骨骼锚定图生成系统-目标定义.md`](docs/骨骼锚定图生成系统-目标定义.md)。
